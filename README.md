# Fireworks Symphony

A browser-based fireworks simulation written in TypeScript. This repository currently contains a simple particle system that launches periodic fireworks on an HTML5 canvas. The project is the foundation for future work such as multiple firework types and music synchronization.

## Development

Install dependencies and compile the TypeScript files:

```bash
npm install
npm run build
```

Open `index.html` in a browser to view the simulation.

## Testing

There are no automated tests yet. Run the test script to confirm:

```bash
npm test
```
